# Third-party textures

`OutdoorGrassFloorD.png` and `OutdoorSkybox2048.png` are copied unchanged from
dm_control, where they are the floor and sky of the `outdoor_natural` arena
(`dm_control/locomotion/arenas/assets/outdoor_natural/`). Copyright The
dm_control Authors. Licensed under the Apache License, Version 2.0; the license
text is in `LICENSE-DM_CONTROL` in this directory.

`RunGap`'s `outdoor_natural` aesthetic loads them from here. `MazeForageVision`
reads the same two files from the installed dm_control package instead.
